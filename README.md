# Image Metadata Lab — лабораторная работа №2

## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в актуальном Chrome или Edge.
3. Нажмите «Выбрать папку» и укажите папку с изображениями.
4. При необходимости используйте фильтр и кнопку «Экспорт CSV».

Внешние библиотеки и сервер не требуются. Файлы обрабатываются локально в браузере.

## Архитектура (три слоя)
1. **Представление (UI):** `index.html`, `style.css`; выбор каталога, таблица, прогресс, фильтр и экспорт.
2. **Слой приложения / бизнес-логика:** `app.js`; очередь задач, ограниченный пул фоновых обработчиков, статистика, отмена и CSV.
3. **Слой анализа / инфраструктура:** `worker.js`, `parsers.js`; чтение файла и разбор заголовков форматов.

## Асинхронность и параллелизм
Выбор файлов и `File.arrayBuffer()` используются асинхронно. Разбор выполняется в Web Workers, поэтому вычисления не блокируют основной поток интерфейса. Число workers ограничено максимум четырьмя. В очередь передаются объекты File, а результат возвращается через `postMessage`.

## Поддерживаемые форматы
- BMP: размеры, битовая глубина, код сжатия, разрешение из стандартного DIB-заголовка размером не менее 40 байт.
- PNG: IHDR, тип/глубина цвета, pHYs, метод сжатия.
- GIF: логический размер холста, глубина индекса цвета, LZW; DPI обычно не задан.
- JPEG: SOF, JFIF DPI и базовые EXIF X/YResolution.
- TIFF: классический TIFF (magic 42), первый IFD, размеры, BitsPerSample, Compression и Resolution.
- PCX: размеры, битовая глубина по плоскостям, DPI, кодирование.

## Важные ограничения
- TIFF BigTIFF (magic 43) пока не поддерживается; анализируется первый IFD/страница.
- JPEG парсер рассчитан на обычные marker-сегменты и не выполняет декодирование изображения. DPI берётся из JFIF или базовых EXIF-тегов.
- GIF не хранит стандартное разрешение печати; глубина цвета относится к размеру таблицы индексов, а не обязательно к числу реально использованных цветов.
- Для PNG глубина цвета рассчитывается по битам на канал и типу цвета; для индексированного PNG это глубина индекса, а не глубина отображаемого RGB.
- Для BMP читается распространённый DIB-заголовок размером от 40 байт; некоторые старые варианты заголовка могут не поддерживаться.
- PCX глубина цвета считается как bits-per-plane × number-of-planes.
- Поля, отсутствующие в файле, отображаются как «—» / «Не указано», они не угадываются.
- Браузер может ограничивать объём памяти при обработке очень больших файлов. `File.arrayBuffer()` читает файл целиком; для сверхкрупных наборов следующий этап оптимизации — чтение нужных фрагментов через `File.slice()`.

## Проверка
Проверьте разные изображения каждого формата, файлы с неизвестным DPI, повреждённые файлы и папку с большим количеством изображений. Сравните результаты с метаданными в другом просмотрщике. CSV экспортируется в UTF-8 с BOM, разделитель — точка с запятой.
